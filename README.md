# Active Circle: final design demos

Clickable demos of the finalised design for the new Active Circle platform, prepared by Weza Designs.

- `index.html`: landing page where you choose a demo
- `app/`: member app demo (7 screens, best on a phone)
- `staff/`: staff system demo (4 screens, best on a laptop)

This is a static design demo, not the working system. Names, prices and dates are samples.
Published with GitHub Pages from the `main` branch, root folder.
